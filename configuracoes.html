⚙️ Configurações do Sistema

🛠️ Passo a Passo: Como Conectar o seu Sistema

Para que a Inteligência Artificial e a gestão de alunos funcionem, precisamos ligar as chaves de acesso. Siga os passos abaixo:

🧠 Passo 1: Chave da API (Inteligência Artificial)

  • 🌐 Acesse o painel da sua IA (ex: Google AI Studio).
  • 🔑 Faça login com a sua conta Google.
  • 👆 Clique no menu lateral em "Get API key".
  • ➕ Clique no botão azul "Create API key".
  • 📋 Copie o código secreto gerado (Chave da API) e Cole no 1º campo abaixo.

📁 Passo 2: ID da Pasta do Google Drive

  • ☁️ Abra o seu Google Drive.
  • ➕ Crie uma nova pasta chamada "Inclusão Conectada oo selecione a pasta dos seus alunos".
  • 🖱️ Abra essa pasta com um duplo clique.
  • 👁️ Olhe para a barra de endereços (URL) no topo do seu navegador. O link será parecido com este:
    drive.google.com/drive/folders/1a2B3c4D5e6F7g8H9i0J
  • ✂️ Copie apenas a mistura de letras e números do final.
  • 📋 Cole esse código no 2º campo abaixo.

⚠️ Zona de Perigo

Estas ações irão desconectar o aplicativo deste dispositivo. Fique tranquilo: os dados dos alunos nas planilhas e no Google Drive não serão apagados.
