🛠️ Como Conectar o seu Sistema

Siga os passos abaixo antes de salvar o seu perfil:

🧠 Passo 1: Chave da IA (Google AI Studio)

  • 1. Acesse o Google AI Studio.
  • 2. Faça login e clique em "Get API key" no menu.
  • 3. Clique no botão "Create API key".
  • 4. Copie o código gerado e cole no último campo abaixo.

📁 Passo 2: ID da Pasta (Google Drive)

  • 1. Crie uma pasta para os alunos no Google Drive.
  • 2. Abra essa pasta e olhe o link no topo do navegador.
  • 3. Copie apenas a mistura final de letras e números.
  • 4. Cole esse código no campo "Pasta Raiz" abaixo.
