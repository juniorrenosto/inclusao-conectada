Termos de Uso e Política de Privacidade (LGPD)

1. Natureza do Serviço e Processamento de Dados

O Inclusão Conectada opera exclusivamente como uma interface de processamento ("Software as a Service"). Não possuímos banco de dados próprio para armazenar os relatórios, históricos, laudos ou diários de bordo dos estudantes.

2. Responsabilidade e Armazenamento (Google Drive)

Todos os dados pedagógicos gerados ou lidos pelo sistema são salvos e operados diretamente na conta do Google Drive vinculada pelo usuário (Professor/Instituição). O usuário é o controlador absoluto dos dados, sendo sua responsabilidade assegurar o consentimento familiar adequado de acordo com as normas da sua Instituição e a Lei Geral de Proteção de Dados Pessoais (Lei nº 13.709/2018).

3. Uso de Inteligência Artificial

A formulação de Planos de Aula, Cartões de Apoio e Estudos de Caso utiliza as chaves de API privadas (Google Gemini) fornecidas pelo próprio usuário. A transmissão de contexto para a Inteligência Artificial é criptografada e os dados não são utilizados pelo sistema central para treino de modelos de linguagem.

4. Sigilo Profissional

Recomendamos aos profissionais de Educação Especial que, ao submeter históricos para adaptação via IA, utilizem apenas as informações estritamente necessárias para a prática pedagógica, omitindo dados médicos excessivamente sensíveis que não afetem a rotina escolar direta.
